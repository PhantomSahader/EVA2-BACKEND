1. Descripción General

Sistema web e-commerce de componentes de hardware y tecnología, diseñado para ofrecer una experiencia comercial moderna. Cuenta con un backend robusto en DRF, persistencia relacional en PostgreSQL, seguridad mediante JWT con claims de roles (`is_staff`), y un frontend dinámico con Rare UI en Tailwind CSS.

2. Stack Tecnológico

  • Backend: Python, Django, Django REST Framework, SimpleJWT.
  • Base de Datos: PostgreSQL (con soporte transaccional atómico `transaction.atomic()`).
  • Frontend: HTML5, JavaScript Asíncrono (Fetch API), Tailwind CSS.

3. Arquitectura de Datos & Endpoints Principales

El sistema maneja modelos relacionales para Categorías, Productos, Perfil de Cliente (con RUT), Carro de Compras Persistente y Órdenes Históricas. Los endpoints clave de la API incluyen:

  • POST /api/token/ (Generación de token JWT con rol is_staff)
  • POST /api/auth/registro/ (Registro público de clientes con RUT)
  • GET / POST /api/productos/ (Gestión de catálogo y control de permisos admin)
  • POST /api/ordenes/checkout/ (Compra segura y atómica con descuento de stock)
